# Expense List 💰

A sleek and modern web application for tracking your daily expenses.

## Features
- Stores user data locally using SQL database.
- Add new expenses with name, amount, and date.
- Delete expenses you no longer need.
- Display total expenses.
- Maintains the monthly and yearly expense record.
- Simple and intuitive user interface.

## Getting Started

### Prerequisites
You just need a modern web browser!

### Installation
1. Clone the repository:
   ```bash
   git clone <repository-url>
   ```
2. Open `index.html` in your web browser.

## Usage
1. Enter the expense name.
2. Enter the amount.
3. Select the date.
4. Click "Add Expense".
5. Review your expenses and total at the bottom.

## Technologies Used
- HTML5
- CSS3
- Vanilla JavaScript
- MySQL
